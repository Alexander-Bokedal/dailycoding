# 002 - Conditionals

Edit `main.lua` in this folder. Type it by hand!

1. Make a variable `score` and set it to any number from 0 to 100.
2. Using `if` / `elseif` / `else`, print one of:
   - `A` if score is 90 or more
   - `B` if score is 80 or more
   - `C` if score is 70 or more
   - `F` otherwise
3. Change `score` a few times and check that each branch works.
4. Make a variable `isRaining` (a boolean: `true` or `false`). Print `Take an umbrella` if it's raining, otherwise `Enjoy the sun`.

Hints (optional):
- Syntax: `if x > 5 then ... elseif x > 2 then ... else ... end`
- Comparison: `>`, `>=`, `<`, `<=`, `==` (equal), `~=` (NOT equal, unlike most languages)
- Booleans are just `true` and `false`; `if isRaining then` is enough.
- Every `if` needs a matching `end`.
