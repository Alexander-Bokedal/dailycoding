# 001 - Hello

Edit `main.lua` in this folder. Type it by hand, don't paste!

1. Print `Hello, World!` to the console.
2. Make a variable `name` holding your name, and print `Hello, <name>!` using it.
3. Make a variable `age` (a number) and print `<name> is <age> years old`.
4. Print the result of `age + 5` on its own line.

Hints (optional):
- `print("text")` writes to the console.
- `local x = 5` creates a variable.
- `..` joins strings: `"a" .. "b"` gives `"ab"`. Numbers get converted automatically.
- Lines starting with `--` are comments.
