# 003 - Loops

Edit `main.lua` in this folder. Type it by hand!

1. Use a `for` loop to print the numbers 1 to 10.
2. Use a `for` loop to print only the even numbers from 2 to 20.
3. Use a `for` loop to count down from 10 to 1, then print `Liftoff!` after the loop.
4. Use a `while` loop to start at `n = 1` and keep doubling it, printing each value, until it goes above 1000.
5. Calculate the sum of the numbers 1 to 100 using a loop and print the result (it should be 5050).

Hints (optional):
- Syntax: `for i = 1, 10 do ... end`
- A third number is the step: `for i = 0, 20, 5 do` counts 0, 5, 10, 15, 20. A negative step counts down.
- Syntax: `while condition do ... end`
- Remember to change the variable inside a `while` loop, or it never stops.
- Keep a running total in a `local sum = 0` created before the loop.
- Modulo (`%`) gives the remainder: `10 % 2` is 0. Not needed here, but good to know.
